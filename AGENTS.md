# AI Agents & Skills Configuration

This repository is equipped with the **Laravel Enterprise Skill Library** located in `.claude/skills/`.

## Active Skills
- `laravel-ai-coding-standards`: Meta-skill for routing and architectural rules.
- `laravel-enterprise-architecture`: Controller, service, repository, and action layering.
- `laravel-api-standards`: RESTful API standards, JSON structures, error formatting.
- `laravel-database-scale`: Schema design, indexes, and queries.
- `laravel-performance`: Query optimization, caching strategies, and asset handling.
- `laravel-security`: Input sanitization, CSRF, CORS, authorization, and rate limiting.
- `laravel-media-management`: Stream and asset handling.
- `laravel-ui-accessibility`: WCAG 2.2 AA compliant components, keyboard navigation, contrast.
- `laravel-responsive-design`: Mobile-first responsive layouts and fluid sizing.
- `laravel-testing-qa`: Pest & PHPUnit test conventions.
- `laravel-code-quality`: Pint formatting, PHPStan type checks.
- `laravel-devops-deployment`: Environment and server runtime configurations.
